# PhishBuddy Branding Assets

Drop brand and presentation images here. The project README references files in
this folder using relative paths, so an image will appear automatically on
GitHub once you commit it with the expected filename.

## Banner

The main README expects the top banner at:

```
assets/branding/phishbuddy-banner.png
```

To use your own design, export it as `phishbuddy-banner.png` and place it in
this folder, then commit. No README edit is needed — the link is already wired.

Recommended specs for a GitHub README banner:

- Width: 1280px (scales cleanly on most displays)
- Aspect ratio: roughly 4:1 to 3:1 (for example 1280x320 or 1280x420)
- Format: PNG with transparency, or SVG if you prefer crisp scaling
- Keep file size reasonable (under ~500 KB) so the README loads quickly

If you choose a different filename or format (for example `.svg`), update the
image path near the top of [`../../README.md`](../../README.md) to match.
